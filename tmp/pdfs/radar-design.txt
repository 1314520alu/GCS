=== PAGE 1 ===
Radar Configuration Dashboard
Overview
Design a modern aviation-style Radar Configuration Dashboard for an ArduPilot Ground Control Station.
The page should use a professional UAV control station appearance inspired by:
• DJI Pilot 2
• QGroundControl
• PX4 Station
• Modern avionics displays
Avoid Mission Planner style parameter tables.
The UI must be card-based, clean, modern, and optimized for desktop use.
Layout
Use a responsive 2-column layout.
Desktop:
• Left Panel: 40%
• Right Panel: 60%
Structure:
Header
├── Device Status Card ├── Installation Card ├── Detection Settings Card
Live Radar View
├── Radar Visualization ├── Obstacle List
